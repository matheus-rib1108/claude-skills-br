# Fazer vídeo

> Categoria: **Redes sociais, foto e vídeo** · nome técnico: `video-maker`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/video-maker.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Faz vídeos .mp4 de verdade: Reels, TikTok, propaganda, explicativo com narração e legenda, slideshow de fotos.

## O que muda no seu Claude
O Claude escreve o roteiro, monta as cenas em código (HyperFrames ou Remotion) e renderiza o arquivo final.

| Sem a skill | Com a skill |
|---|---|
| Só o roteiro em texto. | Arquivo .mp4 pronto em 9:16 ou 16:9. |

## Exemplos de pedido
- "Faz um reels de 15 s do cardápio novo"
- "Vídeo explicando meu projeto do SENAI com legenda"
- "Anima esse texto para o Stories"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Diga o formato (Reels, YouTube) e a duração.
- Mande fotos e logo do cliente para usar nas cenas.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/video-maker/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
