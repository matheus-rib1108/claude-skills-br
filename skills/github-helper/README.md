# Ajudante de GitHub

> Categoria: **Sites e programação** · nome técnico: `github-helper`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/github-helper.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Faz tudo de Git e GitHub: cria repositório, primeiro commit, branches, PRs, releases, GitHub Pages e segurança grátis.

## O que muda no seu Claude
O Claude cuida dos comandos do Git e liga Dependabot, secret scanning e proteção de branch.

| Sem a skill | Com a skill |
|---|---|
| Lista de comandos para você digitar. | Repositório criado, com segurança ligada e o link na mão. |

## Exemplos de pedido
- "Sobe esse projeto para o GitHub"
- "Faz um PR com essa mudança"
- "Publica no GitHub Pages"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Rode gh auth login uma vez.
- Nunca suba senhas ou .env.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/github-helper/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
