# Publicar skills no GitHub

> Categoria: **Criar e publicar skills** · nome técnico: `publicar-skills-github`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/publicar-skills-github.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Monta e publica um repositório público de skills, como este: página de cada skill, downloads, instalação, notas e sugestões.

## O que muda no seu Claude
O Claude sabe montar uma biblioteca de skills completa e pede sua confirmação antes de publicar.

| Sem a skill | Com a skill |
|---|---|
| Skills só no seu computador. | Repositório público com downloads, explicações e avaliações. |

## Exemplos de pedido
- "Publica minhas skills no GitHub"
- "Atualiza o repositório com a skill nova"
- "Cria uma release nova"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Rode a checagem de segredos antes de publicar.
- Não coloque dados pessoais no repositório.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/publicar-skills-github/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
