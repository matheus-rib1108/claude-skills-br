# Instagram de negócio local

> Categoria: **Redes sociais, foto e vídeo** · nome técnico: `legenda-instagram-negocio`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/legenda-instagram-negocio.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Legendas, ideias de post, roteiro de Reels e calendário do mês para o Instagram de um negócio local, com a voz do dono.

## O que muda no seu Claude
O Claude guarda o perfil do cliente, alterna tipos de post e escreve legendas curtas com chamada para ação e hashtags da cidade.

| Sem a skill | Com a skill |
|---|---|
| "Venha conferir nossas delícias! 🍕🔥 #food #pizza #love" | Primeira linha forte, 3 linhas com a voz do dono, CTA para o WhatsApp e hashtags locais. |

## Exemplos de pedido
- "Calendário de outubro para a pizzaria"
- "Legenda para essa foto do hambúrguer"
- "Roteiro de Reels de 20 segundos mostrando o forno"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Preencha o perfil do cliente uma vez e reaproveite.
- Nunca publique promoção sem o dono aprovar.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/legenda-instagram-negocio/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
