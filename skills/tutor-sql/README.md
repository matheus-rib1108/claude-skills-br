# Tutor de SQL

> Categoria: **Estudo** · nome técnico: `tutor-sql`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/tutor-sql.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Professor de SQL/MySQL em português: corrige scripts, explica comandos e cria missões no seu próprio banco de exemplo.

## O que muda no seu Claude
O Claude aponta a linha exata do erro com a mensagem real do MySQL, cobra boas práticas e cria exercícios com dica antes da resposta.

| Sem a skill | Com a skill |
|---|---|
| O script inteiro reescrito sem explicação. | A linha errada apontada, a correção, o porquê em 3 linhas e a query testada. |

## Exemplos de pedido
- "Por que esse JOIN não funciona? (script)"
- "Senha é CHAR ou VARCHAR?"
- "Me dá 5 missões no meu banco de filmes"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Cole o CREATE TABLE das suas tabelas para as missões usarem seus dados.
- Diga "só a dica" para tentar sozinho primeiro.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/tutor-sql/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
