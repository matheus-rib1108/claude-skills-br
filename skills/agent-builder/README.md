# Criar agente pessoal

> Categoria: **Produtividade e PC** · nome técnico: `agent-builder`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/agent-builder.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Cria seus próprios agentes de IA para tarefas que se repetem, como assistente de estudos, de redes sociais ou de sites.

## O que muda no seu Claude
O Claude passa a ter especialistas que você criou e que ele chama sozinho quando o assunto aparece.

| Sem a skill | Com a skill |
|---|---|
| Explicar tudo de novo a cada conversa. | Um agente com as regras salvas, pronto para usar. |

## Exemplos de pedido
- "Cria um agente que organiza minhas anotações no Obsidian"
- "Quero uma IA que monta posts para meus clientes"
- "Um agente revisor dos meus trabalhos"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Descreva a tarefa e um exemplo de resultado bom.
- Comece com um agente pequeno e melhore com o uso.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/agent-builder/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
