# Currículo Jovem Aprendiz

> Categoria: **Estudo** · nome técnico: `curriculo-jovem-aprendiz`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/curriculo-jovem-aprendiz.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Currículo de uma página para primeiro emprego, Jovem Aprendiz ou estágio, usando cursos e projetos como experiência, mais carta e treino de entrevista.

## O que muda no seu Claude
O Claude transforma projetos da escola e do SENAI em experiência real no currículo, tira dados que não devem aparecer e treina a entrevista com você.

| Sem a skill | Com a skill |
|---|---|
| "Sou proativo e dinâmico" e campo de experiência vazio. | Projetos com verbo e resultado, cursos com carga horária e um PDF de uma página. |

## Exemplos de pedido
- "Faz meu currículo para Jovem Aprendiz"
- "Escreve meu LinkedIn"
- "Me treina para a entrevista, uma pergunta por vez"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/curriculo-jovem-aprendiz/SKILL.md`).
