# Matemática passo a passo

> Categoria: **Estudo** · nome técnico: `matematica-passo-a-passo`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/matematica-passo-a-passo.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Resolve exercícios de matemática do ensino médio e técnico explicando cada passo, com desenho da figura e conferência da conta.

## O que muda no seu Claude
O Claude passa a desenhar o triângulo, a escada ou a sombra antes de calcular, diz qual fórmula usar e por quê, faz uma operação por linha e confere o resultado.

| Sem a skill | Com a skill |
|---|---|
| Resposta direta: x = 5. | Figura com os lados marcados, explicação de quais são catetos, conta linha a linha e a resposta em destaque com unidade. |

## Exemplos de pedido
- "Resolve essa lista de Pitágoras e explica como se eu nunca tivesse visto"
- "Por que no seno é oposto sobre hipotenusa?"
- "Me ajuda nessa questão de porcentagem (foto)"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Mande foto nítida, uma questão por vez se a lista for grande.
- Peça "me explica o porquê" para ver a ideia antes da fórmula.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/matematica-passo-a-passo/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
