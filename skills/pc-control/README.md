# Controlar o PC

> Categoria: **Produtividade e PC** · nome técnico: `pc-control`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/pc-control.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Faz o Claude mexer no seu computador e no Chrome logado: abrir programas, usar sites, criar contas com o mínimo de esforço seu.

## O que muda no seu Claude
O Claude sabe o que consegue fazer sozinho e o que precisa de você (senha, CAPTCHA, código do SMS).

| Sem a skill | Com a skill |
|---|---|
| "Não consigo acessar seu computador." | A tarefa feita, parando só onde precisa da sua confirmação. |

## Exemplos de pedido
- "Abre o Obsidian e cria uma nota"
- "Cria uma conta no Canva com meu Google"
- "Instala a extensão do Claude no Chrome"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Prefira "Continuar com o Google" ao criar contas.
- Senha nunca vai no chat: use o gerenciador de senhas.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/pc-control/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
