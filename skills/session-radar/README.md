# Radar de sessões

> Categoria: **Produtividade e PC** · nome técnico: `session-radar`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/session-radar.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Mostra o que está acontecendo nas suas outras conversas do Claude Code (nuvem ou computador), resume e diz o que falta.

## O que muda no seu Claude
O Claude enxerga as outras sessões e responde "como tá aquela conversa do site?" sem você abrir uma por uma.

| Sem a skill | Com a skill |
|---|---|
| Abrir cada conversa para lembrar o que foi feito. | Resumo do andamento e dos próximos passos. |

## Exemplos de pedido
- "O que tá acontecendo na conversa do site?"
- "Em qual sessão eu fiz o login?"
- "O que falta terminar lá?"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Diga uma palavra do assunto para achar a sessão certa.
- Funciona melhor com sessões que têm título claro.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/session-radar/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
