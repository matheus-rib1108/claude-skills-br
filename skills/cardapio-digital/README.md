# Cardápio digital

> Categoria: **Vendas e negócio local** · nome técnico: `cardapio-digital`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/cardapio-digital.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Cria cardápio digital leve com pedido pelo WhatsApp, horário aberto/fechado e QR code de mesa, para publicar de graça.

## O que muda no seu Claude
O Claude monta uma página rápida no 4G, com os itens num JSON que o dono edita sozinho, e gera o QR code para imprimir.

| Sem a skill | Com a skill |
|---|---|
| PDF do cardápio no WhatsApp. | Página com carrinho que manda o pedido pronto pelo WhatsApp do restaurante. |

## Exemplos de pedido
- "Faz o cardápio digital da lanchonete com essa foto do cardápio"
- "Adiciona tamanhos e bordas nas pizzas"
- "Gera o QR code para as mesas"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Peça para o dono conferir os preços antes de publicar.
- Cadastre o link no Google Meu Negócio e na bio do Instagram.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/cardapio-digital/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
