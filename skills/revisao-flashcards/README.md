# Revisão com flashcards

> Categoria: **Estudo** · nome técnico: `revisao-flashcards`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/revisao-flashcards.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Transforma a matéria em resumo de uma página, flashcards, quiz com gabarito comentado e plano de revisão até a prova.

## O que muda no seu Claude
Em vez de só resumir, o Claude monta material de prova: perguntas que exigem raciocínio, quiz no estilo do professor e repetição espaçada até a data.

| Sem a skill | Com a skill |
|---|---|
| Um resumo comprido. | Resumo de 1 página + 20 flashcards em CSV para o Anki + quiz + plano dia a dia. |

## Exemplos de pedido
- "Tenho prova de biologia sexta, faz flashcards dessa foto do caderno"
- "Me testa sobre Revolução Francesa, uma pergunta por vez"
- "Exporta os flashcards para o Anki"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Diga a data da prova para ele montar o plano.
- Os erros do quiz viram flashcards novos automaticamente.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/revisao-flashcards/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
