# Minecraft: construções e mods

> Categoria: **Jogos** · nome técnico: `minecraft-construcoes`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/minecraft-construcoes.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Ajuda com Minecraft Java modado: Litematica, schematics, conversão de Bedrock para Java, comandos seguros e conflitos entre mods.

## O que muda no seu Claude
O Claude lê seus logs, acha o mod com problema e converte construções sem perder blocos.

| Sem a skill | Com a skill |
|---|---|
| Tutorial genérico. | Arquivo convertido com contagem de blocos conferida ou o conflito resolvido. |

## Exemplos de pedido
- "Converte esse .mcstructure para .litematic"
- "Meu /fill deu limite de blocos"
- "Litematica e mapa usam a mesma tecla"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Faça backup do mundo antes de colar estruturas grandes.
- Baixe schematics só de sites confiáveis, nunca .exe.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/minecraft-construcoes/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
