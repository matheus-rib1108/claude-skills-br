# Caçador de skills

> Categoria: **Criar e publicar skills** · nome técnico: `skill-hunter`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/skill-hunter.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Procura skills, agentes e servidores MCP no GitHub, verifica a segurança e instala os bons.

## O que muda no seu Claude
O Claude ganha capacidades novas sozinho, sem instalar nada suspeito.

| Sem a skill | Com a skill |
|---|---|
| Procurar e copiar skills na mão. | Skill lida, checada e instalada, com a fonte anotada. |

## Exemplos de pedido
- "Procura skills de edição de vídeo"
- "Tem alguma skill para WhatsApp?"
- "Atualiza minhas skills"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Peça para ele explicar o que a skill faz antes de instalar.
- Prefira repositórios com licença e manutenção recente.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/skill-hunter/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
