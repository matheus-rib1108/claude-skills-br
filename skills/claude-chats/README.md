# Ler conversas do Claude

> Categoria: **Produtividade e PC** · nome técnico: `claude-chats`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/claude-chats.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Lê suas conversas do claude.ai pela exportação oficial, acha a que você quer e faz no Claude Code o que foi pedido lá.

## O que muda no seu Claude
Você pode começar uma ideia no celular e terminar no computador sem copiar e colar nada.

| Sem a skill | Com a skill |
|---|---|
| Copiar e colar a conversa inteira. | Lista dos pedidos confirmada com você e executada. |

## Exemplos de pedido
- "Faz o que eu pedi na última conversa do Claude"
- "Em qual conversa eu falei do cardápio?"
- "Lista os pedidos daquela conversa"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Exportar: claude.ai → Configurações → Privacidade → Exportar dados.
- Nunca suba a exportação para o GitHub.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/claude-chats/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
