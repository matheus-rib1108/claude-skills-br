# Projeto de desafio SENAI

> Categoria: **Estudo** · nome técnico: `projeto-senai-desafio`

**[⬇ Baixar esta skill (.zip)](https://github.com/matheus-rib1108/claude-skills-br/raw/main/dist/projeto-senai-desafio.zip)** · [Ver o SKILL.md](SKILL.md) · [Voltar para todas](../../README.md)

## O que faz
Estrutura projetos de desafio técnico (Grand Prix SENAI, desafios de empresa): problema, causa raiz, solução, Canvas, custos, KPIs e pitch.

## O que muda no seu Claude
O Claude organiza o projeto no formato que a banca espera, com números e premissas explícitos.

| Sem a skill | Com a skill |
|---|---|
| Ideia solta sem números. | Problema medido, causa raiz, solução, custo, retorno e pitch cronometrado. |

## Exemplos de pedido
- "Monta o Canvas do nosso projeto de estoque"
- "Faz o pitch de 5 minutos dividido em 4 pessoas"
- "Que KPIs usar para almoxarifado?"

Você não precisa citar o nome da skill: o Claude lê a descrição e usa sozinho quando o assunto aparece.

## Dicas
- Todo número estimado deve dizer a premissa.
- Faça o protótipo simples primeiro.

## Como instalar só esta
- **claude.ai ou app**: baixe o zip acima → Configurações → Capacidades → Skills → enviar o arquivo.
- **Claude Code**: descompacte em `~/.claude/skills/` (fica `~/.claude/skills/projeto-senai-desafio/SKILL.md`).

Passo a passo com imagens: [COMO-INSTALAR.md](../../COMO-INSTALAR.md).
